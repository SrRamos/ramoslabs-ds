Adds the RamosLabs Design System (https://design.ramoslabs.com), MIT licensed.

- Mono-indigo, token-first system: color, spacing, typography, radius, shadow, and motion as
  DTCG JSON compiled to CSS variables, TypeScript values, and flat JSON (`@ramoslabs/tokens` on npm).
- Documented foundations and patterns (accessibility, forms, tables, modals, mobile-first,
  voice and tone).
