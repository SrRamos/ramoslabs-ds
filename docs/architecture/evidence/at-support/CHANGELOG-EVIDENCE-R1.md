# Evidence registry changelog — revision 1

Date: 2026-10-27. Scope: all twelve JSON registries, twelve decision notes, and INDEX. The registry now contains 80 entries. ARIA-AT metadata, finalized MUST assertions, AT/browser versions, completion dates, and negative side effects were checked through the public ARIA-AT GraphQL API and the corresponding public report URLs.
